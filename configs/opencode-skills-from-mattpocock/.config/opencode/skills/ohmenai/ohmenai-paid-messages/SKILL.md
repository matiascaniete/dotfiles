# OhMenAI — Paid Messages

## Quick start

1. Identify message type (welcome / FAQ / complaint / reactivation / follow-up / upsell / cancellation)
2. Open [RESPONSES.md](./RESPONSES.md), find the matching template for the platform
3. Personalize: replace `{username}`, `{tier}`, `{product}` with real values
4. Adjust tone to feel human, not templated
5. Send via Fanvue or DeviantArt DM

## Hybrid Tone (DM-specific)

- **Keep from brand:** warmth, confidence, "The Manailands" lore, playful energy, direct address ("you"), max 1 emoji
- **Drop from feed:** Spanglish, elaborate Hook→Tease→CTA structure, cryptic captions, 2+ emojis
- **DM structure:** Greeting → Context → Value/Resolution → Closing
- **Length:** 3-6 lines max. DMs are intimate, not broadcast.

## Workflows

### New subscriber
Send within 24h of signup. Thank, confirm tier access, invite reply.

### FAQ / content question
Answer in 1-2 lines. If tier-specific, clarify what they get at their level. Anchor to `go.ohmenai.com` if relevant.

### Complaint / technical issue
Acknowledge first ("Sorry that happened"). Solve or escalate. If download issue on DA, confirm DeviantArt purchases page access. On Fanvue, content is accessed in-app — no external links. If unmet expectations, clarify tier scope.

### Reactivation (Fanvue expired)
Send when sub lapses >7 days. No pressure. Just remind what they're missing and offer the bundle discount.

### Post-purchase follow-up (DeviantArt one-time)
Send 24h after purchase. Confirm delivery, offer upgrade path.

### Upselling
Only when context fits (e.g., they ask about content volume, resolution, or pricing). Don't sell unprompted.

### Cancellation / goodbye
Acknowledge, leave door open, no guilt.
