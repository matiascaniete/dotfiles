# Obsidian — Collect Ideas

Pipeline: Scan → Extract → Develop → Save → Index

## Configuration

| Param | Default | Description |
|-------|---------|-------------|
| `vault_root` | `.` | Vault root directory |
| `profile_file` | (required) | Path to `USER.md` (generated by `personal-profiler`). Flat `§`-delimited entries |
| `output_dir` | (required) | Destination folder inside vault for collected ideas |
| `idea_tags` | `#idea`, `#ideafor*` | Tags that mark raw ideas in notes |
| `filename_patterns` | `*Ideas*`, `Ideas for*` | Filename patterns for dedicated idea notes |

## Workflow

### 1. Scan

Grep for `idea_tags` across all `.md` files. Glob for `filename_patterns`.
Exclude `.obsidian/`, template folders, `.base` files, and the `output_dir` itself.
Record per hit: raw text, source file, tag, line number.

### 2. Develop

For each idea:

- **Type** — infer from tag. Strip `#ideafor` prefix (e.g. `#ideaforbook` → `book`). Bare `#idea` / `#ideas` maps to `general`.
- **Title** — generate a concise, descriptive title. Use the vault's primary language.
- **Profile match** — read `profile_file` (flat `§`-delimited entries, no markdown sections). Parse entries by category label (Identity, Interests, Influences, Projects, Goals, Traits). Cross-reference idea text against each entry. Lexical overlap determines relevance. Generate 2–4 `[[wikilinks]]` to named entities found in the profile. Record which category matched.
- **Deduplicate** — skip if identical text or title already exists in `output_dir`. When found in multiple sources, keep the oldest occurrence as canonical; note the others as cross-references.

### 3. Save

Create one note per idea using this template:

```
---
idea_type: {type}
source: "[[{source_file}]]"
profile_rel:
  - "[[USER.md]] ({category})"
tags:
  - idea-desarrollada
  - {original_tag}
created: {YYYY-MM-DD}
---

# {Title}

## Idea original
{raw text from vault, verbatim}

## Conexiones con el perfil
- [[Entity]] — {reason for connection}
- [[Concept]]

## Notas
_Espacio para desarrollo futuro._
```

### 4. Index

Create or update `{output_dir}/Índice de Ideas.md` with `[[wikilinks]]` grouped by `idea_type`.

## Rules

- Preserve the original language of the idea text
- The `Notas` section is left empty — it is populated by the companion skill `obsidian-group-ideas`
- Profile matching is lexical: parse `USER.md` `§`-delimited entries by category, find keyword overlap between the idea text and each entry
- All output goes inside `output_dir` under `vault_root`
