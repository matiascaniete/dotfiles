# Obsidian — Group Ideas

Pipeline: Read → Cluster → Rank → Save → Index

## Configuration

| Param | Default | Description |
|-------|---------|-------------|
| `ideas_dir` | (required) | Folder containing collected idea notes |
| `profile_file` | (required) | Path to `USER.md` (generated by `personal-profiler`). Flat `§`-delimited entries |
| `output_dir` | same as `ideas_dir` | Where themed notes are saved |

## Workflow

### 1. Read

Load all individual idea notes from `ideas_dir`. Skip index notes and themed notes (those whose `idea_type` is missing or whose content matches the themed-note template).
For each note, parse frontmatter: `idea_type`, `source`, `profile_rel`, tags, title. Parse body: `## Idea original` content and `## Conexiones con el perfil` links.

### 2. Cluster

Group ideas by thematic affinity:

- Parse `profile_file` flat entries by category (Interests, Projects, Influences, Goals, etc.)
- Each profile category becomes a candidate theme bucket
- Assign each idea to the theme whose category it links to in `profile_rel`
- Ideas linking to multiple categories are assigned to the one with the strongest lexical match
- Ideas with no clear match go to a catch-all `General` theme

### 3. Rank

Score each idea within its theme:

- Profile category match — **+1** per matching category entry
- Named person / entity match — **+2** per person from the profile's influence lists
- Interest keyword overlap — **+1** per profile interest keyword found in the idea
- Goal / project mention — **+3** per explicit profile goal referenced

Sort by score descending. Split into three tiers:

| Tier | Threshold |
|------|-----------|
| Prioridad alta | Top third of scores |
| Prioridad media | Middle third |
| Prioridad baja | Bottom third |

### 4. Save

Create one note per theme:

```
---
theme: {name}
profile_rel: "[[USER.md]] ({category})"
idea_count: {N}
created: {YYYY-MM-DD}
---

# {Theme} — Ideas

## Prioridad alta
- [[Idea A]] — {one-line summary from its Idea original}
- [[Idea B]] — {one-line summary}

## Prioridad media
- [[Idea C]] — {one-line summary}

## Prioridad baja
- [[Idea D]] — {one-line summary}
```

### 5. Index

Create or update `{output_dir}/Índice de Temas.md` with `[[wikilinks]]` to all themed notes, ordered by total idea count per theme (most ideas first).

## Rules

- Rankings are relative within each theme, not global
- Ideas with score 0 still appear in `Prioridad baja` — they are not discarded
- Preserve the original language of idea summaries
- Themed notes overwrite previous versions on re-run (idempotent)
